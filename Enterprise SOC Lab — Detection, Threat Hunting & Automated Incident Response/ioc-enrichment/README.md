# IOC Enrichment

This directory documents the enrichment and contextual analysis of observables identified during the Project 4 SOC simulation.

## Objective

Demonstrate how a SOC analyst evaluates an observable before taking containment or blocking action.

## Enrichment Workflow

```text
Observable
    ↓
Identify Type
    ↓
Collect Context
    ↓
Threat Intelligence
    ↓
Reputation
    ↓
Correlate With Endpoint Activity
    ↓
Analyst Assessment
    ↓
Response Decision
```
